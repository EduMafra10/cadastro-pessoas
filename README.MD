# Cadastro de Pessoas

Projeto acadêmico de CRUD desenvolvido com HTML, CSS, JavaScript,
Node.js, Express e JSON Server.

## Funcionalidades

- Cadastro de pessoas.
- Listagem de todos os registros.
- Busca por CPF.
- Edição dos dados.
- Exclusão com confirmação.

## Organização

- public/post: página e script de cadastro.
- public/get: página e script de consulta.
- public/put: página e script de edição.
- public/delete: página e script de exclusão.
- public/css: estilos compartilhados.
- server.js: servidor da aplicação.
- db.json: armazenamento dos cadastros.

## Executar localmente

1. Instale as dependências com npm install.
2. Inicie o servidor com npm start.
3. Acesse http://localhost:3000.

Utilize apenas dados fictícios nos cadastros de demonstração.
